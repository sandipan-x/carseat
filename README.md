# CarSeat

Car seat stages by age and weight: find the right stage now, get transition checklists, install tips, and check expiry. Free tool.

## Features
- Stage finder by age, weight, and height with transition checklists
- Installation angle and snugness guide with safety checks
- Car seat expiry checker from manufacture date
